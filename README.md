# Где дешевле?

Веб-приложение для сравнения цен на товары российского рынка.

## Требования к первой рабочей версии
- Удобная мобильная и настольная версия.
- Поиск по товарам, категории, фильтры и сортировка по цене.
- Карточка товара: название, изображение, магазин, цена, дата обновления, ссылка на магазин.
- Отображение источника и актуальности цены; никаких выдуманных цен или скидок.
- Раздел избранного.
- Отслеживание переходов без сбора лишних персональных данных.
- PWA с установкой на телефон.
- Административный способ обновлять каталог.

## Важные ограничения
Пока не подключены разрешённые источники цен и партнёрские программы, демонстрационные данные должны быть явно помечены. Нельзя выдавать тестовые данные за актуальные предложения. Рекламный бюджет 3000 ₽ не расходуется без подтверждения владельца.

## Этапы
1. Рабочий интерфейс и проверка владельцем.
2. Исправления и доведение функций до согласованного состояния.
3. Подключение источников цен и проверка ссылок.
4. Публикация и только после одобрения тест рекламы.

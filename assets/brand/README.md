# Купиора / Kupiora — варианты бренда A, B, C

29 октября 2026. Палитра текущей ветки: синий #0875ff, тёмный #10172b, светлый #f8fbff; добавлены бирюзовый, оранжевый и фиолетовый акценты.

Геометрия создана в SVG вручную в этом проекте, без трассировки ранее сгенерированных картинок или чужих логотипов. Это три предложения для выбора, не замена действующего знака.

- **A:** бирюзовая сумка с улыбкой, синей ручкой и небольшим оранжевым ценником без надписей/процентов.
- **B:** монограмма «К» с сине-бирюзово-фиолетовым градиентом.
- **C:** оранжевая тележка с улыбкой, бирюзовой ручкой и синими колёсами.

## Предпросмотр

При работающем локальном сервере проекта: http://127.0.0.1:8879/assets/brand/preview.html . Либо откройте `preview.html` как локальный файл: внешние библиотеки и сетевые шрифты не нужны.

Страница содержит все три варианта, горизонтальные логотипы на светлом/тёмном фоне, размеры 32/48/64 px, миниатюру шапки и макет телефона с существующими фотографиями категорий. Макет телефона обозначен как иллюстративный, не имитирует действующую покупку. Переключение окружения и кнопки выбора влияют только на эту страницу.

Снимки проверки: `preview-light.png`, `preview-dark.png`, `preview-mobile.png`.

## Требования платформ и границы готовности

- [Google Play: icon design specifications](https://developer.android.com/distribute/google-play/resources/icon-design-specifications): 512×512, sRGB, 32-bit PNG, до 1024 КБ; полное квадратное поле, без внешней тени и готовой скруглённой маски. Эти параметры проверены скриптом.
- [Android adaptive icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive): отдельные foreground/background и monochrome; важная геометрия foreground размещена внутри центральной безопасной окружности диаметром 66 из 108 единиц. Маски телефона в HTML применяются только для иллюстрации, исходные store PNG остаются квадратными.
- [Apple app icons](https://developer.apple.com/design/human-interface-guidelines/app-icons), [asset catalog](https://developer.apple.com/documentation/xcode/configuring-your-app-icon): подготовлен плоский непрозрачный мастер 1024×1024 и тёмная версия. Скругление выполняет система. Для нативного выпуска нового поколения иконок Apple потребуется импорт слоёв в Icon Composer / Xcode, проверка системных материалов и экспорт нативного asset catalog. Набор SVG/PNG сам по себе не является готовым пакетом Icon Composer и не означает прохождение модерации.

В существующий APK, PWA manifest, Android resources или Xcode asset catalog эти варианты пока не подключены. Выбор владельца и отдельная сборка приложения требуются перед заменой.

## Будущий A/B-тест

`experiment.json` содержит веса A/B/C и **enabled: false**. `experiment.cjs` — чистая функция стабильного распределения по переданному случайному анонимному ID и версии эксперимента. Приложение её не импортирует. Сетевых запросов, телеметрии, сбора идентификаторов и смены действующего логотипа нет.

После выбора стратегии и разрешения запуска:

1. Использовать случайный ID установки/браузера, а не email, телефон, имя или fingerprint. Сохранять вариант на всё время эксперимента, не менять его при каждом открытии.
2. Добавить в приложение управляемую конфигурацию и явный fallback к утверждённому знаку. Не включать эксперимент до готовности иконок/сборок и согласования аналитики.
3. События будущей аналитики: `brand_exposure`, `smart_cart_open`, `smart_cart_add`, `merchant_outbound`. Передавать версию/вариант, без товарных URL с токенами и персональных данных. Число открытий не считать покупками или прибылью.
4. До запуска зафиксировать длительность, выборку, основную метрику и критерий остановки; тестировать одно изменение, сохранять доступность. Здесь метрики и результаты не выдумываются.
5. Иконку установленного приложения нельзя просто менять веб-экспериментом: для Apple alternate icons и Android launcher resources нужны отдельная нативная интеграция/сборка. Иконки магазина тестируются средствами соответствующей консоли отдельно от шапки сайта.

Проверка функции: при выключенном флаге — null; для 3000 синтетических локальных seed результат стабилен, распределение A=990, B=992, C=1018. Это техническая проверка распределения, не пользовательский эксперимент.

## Воспроизведение и результаты проверки

`node assets/brand/generate.cjs` — детерминированная генерация. Использует имеющийся bundled sharp; в другой среде можно передать путь к модулю через `KUPIORA_SHARP`. Приватные токены и внешние API не используются.

`node assets/brand/validate.cjs` — **66 проверок прошли**: размеры, непрозрачность, отсутствие alpha в Apple PNG, формат/размер Google Play, структура ICO, безопасная окружность adaptive foreground, отсутствие внешних ссылок и скриптов внутри SVG.

Браузер: все 33 изображения загрузились, ошибок console error/warn нет; светлое и тёмное окружения и кнопка выбора работают. На ширинах 320/375/430 scrollWidth равен clientWidth, битых картинок нет. Визуально проверен общий лист, включая малые размеры. Физические телефоны и системные маски Android/iOS не проверялись.

Изменения этой задачи ограничены новой папкой `assets/brand/`. Функциональность приложения, текущий логотип, manifest, URL и репозиторий не менялись; публикации/объединения нет.

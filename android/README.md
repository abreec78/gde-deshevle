# Радар жизни — Android 0.23

Android 8+ (API 26), Java / Android Views, compile/target SDK 36.

## Что работает
- Первое знакомство — один экран без прокрутки с адаптивной компоновкой и слайдером активации. На нём две статические красные точки и колокольчик с цифрой 2; они не создают записей истории.
- 12 направлений, 159 узлов, 118 конечных интересов. Название открывает описание, переключатель отдельно меняет подписку. Поиск и тестовые кнопки убраны.
- Радар с обычными TextView-подписями. Красная точка у направления открывает его непрочитанные уведомления, после прочтения гаснет. Для остальных направлений доступен счётчик в списке тем.
- Изменения хранятся в уведомлениях отдельно, с категорией и официальным источником. Есть фильтры и отметки прочтения, тёмная/светлая темы.
- Локальная очередь хранит документы до доставки; временное отсутствие документа в следующем ответе не очищает очередь. Повторные синхронизации объединяются. Выключенные темы не вызывают новых уведомлений.
- Показаны дата серверного сбора, доступность источников, очередь проверки и время загрузки на телефон.
- Потребительская корзина в Покупках и правах: только архивный срез апреля 2026, выбор региона и геолокация по согласию. См. BASKET.md.

## Реальные ограничения
Сборщик ежедневно загружает официальные документы, но не одобряет выжимки автоматически. Подключены Банк России, ФНС, Минздрав, СФР (семья, пенсии, нетрудоспособность); успешность каждого сайта отражается в данных. На последней проверке доступны Банк России и СФР; ФНС возвращает 403, Минздрав — ошибку TLS, правовой портал недоступен и его импорт не подключён. TLS не отключается.

В потоке сейчас три проверенные архивные карточки; обнаруженные документы в очереди не выдаются за новые проверенные изменения. Дата принятия документа не подменяет дату публикации. Нельзя гарантировать новое содержательное уведомление каждый день.

Проверка телефона: JobScheduler каждые 24 часа с сетью, сводки раз в день / три дня / неделю / месяц. Android может задержать работу. Серверный push не подключён. Для системных уведомлений нужно разрешение пользователя и включённый канал. Сами непрочитанные записи сохраняются в приложении и без разрешения.

## Данные и сборка
Настройки и история — приватные SharedPreferences на устройстве. Персональные параметры не отправляются в GitHub. Координаты не сохраняются. На GitHub только код и общедоступные официальные данные.

Сборка: gradlew.bat assembleDebug lintDebug testDebugUnitTest.
Отдельный проверочный APK: assembleDebugAndroidTest. Он не входит в пользовательский APK; после проверок удаляется с эмулятора.

Передаваемый APK подписан отладочным ключом для установки напрямую. Это не магазинный релиз. Сохранённая Финальная версия 1 остаётся отдельной контрольной копией.

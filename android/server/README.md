Сборщик официальных документов. Запуск из любой папки: python tools/update_legal.py (путь относительно этой папки server). Нужен curl с проверкой TLS. Данные пишутся в radar/, история — radar/legal-history/. Автоматическое одобрение выжимок отсутствует. Рабочее ежедневное расписание и публикация Pages находятся в основном репозитории: .github/workflows/daily-legal.yml. Личные настройки пользователей сюда не поступают.

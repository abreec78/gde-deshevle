# Купиора: передача карточки из браузера

Локальный прототип расширения Manifest V3 для Chromium. Ничего платного, нет внешних библиотек. Расширение ещё не установлено и не проверено на настоящих карточках в пользовательском браузере.

Для проверки: открыть страницу управления расширениями, включить режим разработчика, выбрать «Загрузить распакованное» и эту папку. Установку и предоставление доступа выполняет владелец браузера.

Открыть товар Ozon/WB/Маркета/Ситилинка обычным способом, нажать расширение. Проверить название в окне и нажать «Передать в Купиору». Только после этой кнопки открывается сайт с выбранными полями карточки. Cookies, пароли, банковские данные, история и содержимое аккаунта не запрашиваются. activeTab и scripting дают доступ только после нажатия пользователя; постоянных host_permissions нет.

Извлекаются JSON-LD Product либо видимый h1. Это наблюдение страницы, не независимое подтверждение товара. Несколько разных Product отклоняются. Цены не извлекаются во избежание смешивания обычных и условных цен. Серверное сравнение магазинов ещё не подключено. CAPTCHA и блокировки не обходятся.

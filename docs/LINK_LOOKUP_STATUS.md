# Поиск по ссылке: подтверждённое состояние

Обновлено: 01.11.2026, Europe/Moscow.

## Работает
- Тестовый сервер Render: https://kupiora-preview.onrender.com/.
- Введённая ссылка не заменяется фиксированным Samsung, в том числе после перезагрузки demo=1&q=… .
- /api/identify пробует прочитать публичный JSON-LD Product с разрешённых доменов. Нет платных запросов, обхода CAPTCHA, прокси обхода блокировок или использования аккаунта покупателя.
- Адреса вне списка разрешённых доменов отклоняются до сетевого запроса. Перенаправления проверяются отдельно. Название из URL не считается подтверждённой моделью.
- Если страница содержит несколько отличающихся Product, локальная доработка отклоняет неоднозначность; повтор одинаковой разметки допустим. Доработка опубликована на тестовом Render.

## Не работает / не подтверждено
- Произвольные реальные карточки Ozon и Маркета не гарантированно распознаются. По одной карточке каждого магазина проверено локально: доступные метаданные не получены. Для той же карточки Ozon проверено с Render: identified=false, offers=[]. Это не доказательство недоступности всех карточек.
- Автоматическое получение и сравнение актуальных межмагазинных предложений не подключено. /api/status: enabled=false. Неизвестная доставка не равна бесплатной.
- Публичный бесплатный тест Parser.market показывает «Тестовый парсер временно недоступен». В браузере нет авторизованной сессии провайдера. Предложение поддержки о 500 проверках после регистрации не означает уже выданного доступа.
- Новые аккаунты/ключи/соглашения и платные запросы не создавались/не включались.

## Проверки
- На текущем локальном коде: 48 Python + 85 JavaScript PASS; есть прежние ResourceWarning в старых тестах.
- HTTP-тесты локально проверяют отклонение недопустимого URL, передачу метаданных без вымышленных предложений и закрытый доступ к Python-исходникам.
- Последний проверенный опубликованный коммит: 873e9c1, Render live.
- main и PR2 не изменялись этой работой.

## Решение владельца: только бесплатные источники
01.11.2026 владелец прямо отказался от платных сервисов и пробных тарифов с последующей оплатой. Parser.market исключён из плана подключения, включая регистрацию для бесплатного пилота. Не запрашивать повторно регистрацию, оплату или создание ключей этого сервиса. Существующий код адаптера сохранён, платные запросы должны оставаться выключенными.

## Следующий существенный шаг
Проверять только бесплатные официальные партнёрские источники и доступные публичные метаданные без обхода ограничений. Маркетинговое упоминание API/фидов не подтверждает наличие доступа для этого аккаунта. API продавца не считать общедоступным API всего каталога. Если источники недоступны, прямо сообщать об ограничении вместо подстановки товара или цен. Не повторять безрезультатные запросы и не перезапускать исправный сервер.

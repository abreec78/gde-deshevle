# Сравнение по ссылке на конкретный товар

В строку поиска «Купиоры» можно вставить прямую ссылку карточки:
- Ozon: https://www.ozon.ru/product/samsung-ssd-12345678/
- Wildberries: https://www.wildberries.ru/catalog/247318779/detail.aspx
- Яндекс Маркет: https://market.yandex.ru/card/elektrobritva-braun/103683837950

После перехода открывается карточка с названием, исходной ссылкой, фотографией из источника (если получена) и кнопкой «Сравнить цены». Кнопка всегда реагирует. Если исходная карточка ещё загружается, сравнение будет запрошено после её подтверждения. При отсутствии API кнопка показывает 18 переходов в магазины и объяснение, почему автоматические цены недоступны.

## Разделение настоящих и похожих предложений

После подключения источника приложение запрашивает исходную карточку по её ID (market=ozon / wb / ym). Только после нажатия «Сравнить цены» запрашиваются две другие поддержанные площадки. Подтверждённые совпадения одного товара сортируются по цене, отдельно показаны похожие, но неподтверждённые предложения. Цена доставки и индивидуальные скидки могут изменить итоговую стоимость. Из 18 ссылок на магазины только Ozon, Wildberries и Яндекс Маркет предусмотрены для автоматического поиска через Parser.market; остальные открывают поиск на площадке или в Яндексе.

Если у карточки WB нет названия в URL, браузер без API не может угадать точную модель по одному ID. Поэтому не отображает вымышленные фото/цены; ссылки по одному артикулу WB не гарантируют совпадений.

## Приватный тест с API-ключом

Сайт на GitHub Pages не может выполнять Python или безопасно хранить API-ключ. Локальный сервер `tools/private_compare_server.py` слушает только `127.0.0.1:8872`. Для запуска (PowerShell в корне проекта):

~~~powershell
$env:PARSER_MARKET_API_KEY = 'ВАШ_КЛЮЧ'
$env:KUPIORA_ENABLE_PAID_CHECKS = 'yes'
python tools/private_compare_server.py
~~~

Откройте http://127.0.0.1:8872/compare-any.html

ВНИМАНИЕ: запросы API могут расходовать бонусные или оплаченные проверки; параметр `KUPIORA_ENABLE_PAID_CHECKS=yes` означает явное разрешение на их запуск. Живые запросы с настоящим ключом ещё не проверялись.

Документация: https://parser.market/dokumentacziya/ и https://parser.market/parser-cen-json-api/

Для работающего автоматического сравнения на публичном kupiora.ru нужен отдельный защищённый backend с ключом, контролем затрат и лимитами. Статический GitHub Pages этого обеспечить не может.

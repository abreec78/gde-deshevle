# Поиск товара по ссылке Ozon

На главной странице «Где дешевле?» можно вставить прямую ссылку Ozon вида https://www.ozon.ru/product/samsung-ssd-12345678/ либо название товара. Поиск откроет страницу compare-any.html в прежней сине-белой стилистике.

GitHub Pages не может самостоятельно узнавать цены с произвольной карточки Ozon. Без API интерфейс распознаёт ID карточки и извлекает предварительное название из URL для ссылок на поиск в 18 магазинах, но не объявляет самую низкую цену. Сокращённые ссылки ozon.ru/t/... пока требуют получения полного адреса.

## Личный автоматический режим

Локальный сервер: tools/private_compare_server.py. Команды Windows PowerShell:

~~~powershell
$env:PARSER_MARKET_API_KEY = 'ВАШ_КЛЮЧ'
$env:KUPIORA_ENABLE_PAID_CHECKS = 'yes'
python tools/private_compare_server.py
~~~

Адрес: http://127.0.0.1:8872/compare-any.html

После ввода прямой ссылки Ozon backend сначала запрашивает карточку в режиме market=ozon, после получения проверенного названия запускает запросы поиска в Wildberries (wbs) и Яндекс Маркете (ym). Для обычного текста предусмотрен поиск ozons/wbs/ym. Нужен действующий API-ключ; задания могут расходовать платные и бонусные проверки.

Результаты без достоверного совпадения модели не считаются «самыми дешёвыми». Даже совпавшие товары могут отличаться стоимостью доставки и скидками.

Документация: https://parser.market/parser-cen-json-api/ и https://parser.market/dokumentacziya/

**Реальный запрос с ключом пока не выполнялся.** Для автоматической проверки цен из публичного kupiora.ru потребуется отдельный сервер с защищённым ключом и лимитами расходов: GitHub Pages сам по себе не выполняет backend. Остальные магазины из списка 18 доступны через ссылки поиска; автоматический сбор их цен не реализован.

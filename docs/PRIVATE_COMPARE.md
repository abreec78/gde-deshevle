# Личное сравнение любых товаров

Откройте \`compare-any.html\` на текущем сайте. Поиск по 18 магазинам работает **без API** (открываются страницы поиска), реальные цены вводятся вручную либо импортируются из отчётов Parser.market JSON. Фото берутся из данных JSON/заданной прямой ссылки. Данные сохраняются только в localStorage браузера и экспортируются в JSON. Никаких вымышленных предложений в этом экране нет.

## Автоматический режим для Ozon, WB, Яндекс Маркета

В корне проекта запустите локальный приватный сервер (Python 3.10+). Он обслуживает сайт по адресу \`http://127.0.0.1:8872/compare-any.html\`.

Windows PowerShell:
\`\`\`powershell
$env:PARSER_MARKET_API_KEY = 'ВАШ_КЛЮЧ'
$env:KUPIORA_ENABLE_PAID_CHECKS = 'yes'
python tools/private_compare_server.py
\`\`\`

Внимание: каждый поисковый запрос отправляет **три платных задания** Parser.market. Даже бесплатные бонусные проверки расходуются. Если не хотите использовать платные проверки, не устанавливайте \`KUPIORA_ENABLE_PAID_CHECKS=yes\`. Не передавайте секреты по сообщениям и не размещайте их в GitHub.

API: https://parser.market/parser-cen-json-api/ (send-order, get-last50). Сбор выполняется асинхронно. Поиск по названию может дать несколько похожих моделей; их нельзя автоматически считать одинаковыми товарами. Яндекс Маркет по документации провайдера использует Москву независимо от выбранного региона. Изображения доступны только там, где отчёты действительно содержат \`Offer_pics\`. Доставка из отчётов в прототипе намеренно не считается достоверной.

Реальный вызов с аккаунтом не выполнялся: API-ключ неизвестен. После подключения необходим живой тест ошибок, формата и стоимости. Режим без API работает независимо.
